# 客户展示：多箱连续上料

状态：已通过完整三箱物理搬运及 GUI START/RESET 验收。最近完整运行 `passed=true`，用时 210.100 s（仿真时间），335.007 s（现实时间）。

## 展示目标

一次 START 连续收集 3 个箱子，送到同一工作台的 3 个独立位置，最终退让展示整齐排列的结果。RESET 恢复全部箱子、机器人、地图、计时和完成计数。

保留原有 300×240×220 mm、1 kg 箱体作为起点；将取料区布置在工作台附近，单程约 2–3 m，避免旧任务两工位间约 10 m 的长距离横穿。箱子分开放置，取箱通道与已完成箱位互不干扰。目标台 1.6 m 长边可布置三个箱位，中心间距 0.55 m，保留台边余量。

## 单轮流程

1. 展示三个待搬箱子、空工作台和进度 0/3。
2. 选择当前箱子，导航到预抓取点，深度观测并对齐。
3. 双臂夹抱、确认双侧接触、抬起并确认离开支撑面。
4. 经短路线送往对应台面箱位，降低到台面，确认支撑后释放。
5. 连续稳定验收后计数加一，退出桌边，继续下一箱。
6. 三箱均稳定且机器人退让后显示完成及总耗时。

中途失败停止，显示具体箱号和阶段；不跳过失败箱，不以动作播放完毕代替搬运成功。已放置箱子在后续搬运期间继续监测，避免最终只验证最后一个箱子。

## 演示节奏

优先缩短往返路线和重复停顿。空载指令速度 0.65 m/s、载箱速度 0.35 m/s；这些是仿真任务参数，并非硬件批准值。近距离抓放保持低速，保留接触确认和稳定判定时间。提速版完整三箱实测约 3 分 30 秒仿真时间、5 分 35 秒现实时间，平均约 70 秒仿真时间/箱，包含往返取料、升降、抓放与验收。界面计时是仿真时间，实际墙钟时间取决于渲染和机器负载。

提速版在空载返程时同步下降升降柱，停靠速度为 0.14 m/s，导航到位停顿缩短为 0.25 s。物理步长仍为 1/120 s，演示会话的关节求解迭代为位置 32 / 速度 8；报告记录实际求解参数、现实耗时及各部分性能计时。

界面默认使用单个全局相机，点击 `4 CAMERAS` 可切换四路相机，点击 `OVERVIEW` 返回全局画面；四路模式下辅助相机每三个显示帧更新一次。原生 `Viewport` 标签仍可用。

界面突出完成数、当前动作和总计时；主视角采用斜俯视，能同时看见地面取料区、升降动作与工作台。三箱及对应台面位置使用黄、蓝、绿标识，保留腕部和头部相机用于观察抓放。

## 运行与配置

```bash
./scripts/simctl console
./scripts/simctl demo
./scripts/simctl console --console-test --exit-after-test
```

`config/demo_config.json` 定义三处地面取料位置、台面箱位偏移、移动速度和升降行程；`scripts/floor_demo.py` 执行整批任务。物体仅在初始化/RESET 时设置位姿。抓取、运输、放置全程使用关节驱动及刚体摩擦接触。

头部相机在较远处观测地面箱子和地面支撑平面；靠近时箱子会离开头部相机视野，因此最后一段使用已观测位置与激光/编码器定位。该阶段的位置估计误差会影响夹抱，需要物理测试。相机分割仍是仿真实例标签，不是真实物体识别网络。

无界面运行生成 `outputs/demo_report.json`、`demo_telemetry.jsonl` 和 `demo_boxN_*.png`。GUI 展示不逐阶段截图；START 只运行一批，RESET 后可再次开始。全部三箱的位姿、释放状态、稳定验收及已完成数均写入报告。

## 实现与验收

运行时使用独立多箱配置和入口，每个箱子有独立初始位置、目标箱位、接触状态与验收器；感知按当前箱子的实例路径过滤。任务阶段切换不得重置机器人、SLAM 或已放置箱子。RESET 才恢复全部初始状态。

验收应包含：单箱地面抓放（若选择地面方案）、完整三箱、第二箱过程中 RESET、失败停止、完成后的全部箱子稳定性、GUI START/RESET 与进度一致性。记录每箱耗时、总耗时、箱体倾角、接触丢失和最终位置；本次验证为固定场景下的完整运行与中断/复原回归，不是随机初态或真机成功率统计。

台面停靠测距目标为 0.32 m，放箱 TCP 前伸目标为 0.52 m，以避开工作台下部结构。释放后张开并收手，再用 SLAM 位置/朝向反馈后退 0.5 m；停靠 12 秒无进展则中止。连续笛卡尔轨迹按 30 Hz 采样，沿已发送目标衔接，避免受力偏差使下一段动作卸掉夹紧力；原关节力矩限值和 0.35 rad 单步跳变保护保留。

三只任务箱子的自动休眠关闭，持续更新释放后的速度及接触反馈；不会因为已经计数就停止检查前面箱子的状态。报告包含逐箱接触对象、线/角速度和连续稳定时间。
